# Bunny's Cozy Garden landing page

GitHub Pages landing page for **Unbothered Animals: Bunny's Cozy Garden** by Glenda E. Tress.

## Publish

Create a public repository named `unbothered-bunny`, then upload every file from this folder to the repository root. In **Settings → Pages**, publish from the `main` branch and `/ (root)`.

The page uses the existing MailerLite form and reusable Cozy Coloring Sampler.
